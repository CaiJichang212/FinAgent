# 珀莱雅（603605）多空论证（2026-05-22）

## 一、核心争论命题

珀莱雅在经历2025年营收利润双降、2026Q1继续承压后，当前股价（58.19元）较52周高点（91.72元）回撤约37%，PE（TTM）降至15.6倍的历史估值底部区域。市场核心争论的是：**当前是国货美妆龙头的"价值陷阱"还是"周期底部"？**

---

## 三、看多论证

- **核心观点**：主品牌调整接近尾声，多品牌矩阵即将进入收获期，花知晓并表将成为业绩与估值双重催化剂，当前15倍PE的国货美妆龙头被显著低估。

- **主要证据**：

  1. **毛利率持续提升、现金流大增，证明基本面质量不降反升**：2025年毛利率73.26%（+1.87pct），2026Q1进一步提升至74.53%；经营现金流2025年大增98%至21.93亿元。收入端的下滑主要来自天猫直营渠道的结构性调整，而非品牌力或产品力的根本性衰退。公司在天猫平台面霜、面膜品类仍排名第1。

  2. **花知晓收购是战略级催化剂**：花知晓2025年净利2.80亿、2026Q1净利1.55亿（已达珀莱雅Q1净利的42%），并表后将直接增厚2026年利润约1.5亿+。按并表后利润推算，实际PE可能降至13-14倍。花知晓自2019年出海日本，已进入东南亚、北美、欧洲市场，为珀莱雅国际化战略提供了被验证过的路径。

  3. **第三梯队品牌高增长验证了平台化孵化能力**：OR（+102%）、原色波塔（+125%）、惊时（+442%）的高速增长，说明公司不只是"珀莱雅单一品牌"的故事。洗护品类2025年营收增长117.9%，毛利率72.5%（+4.7pct），已形成规模化的第二增长曲线。

  4. **估值处于历史底部，机构一致看多**：当前PE 15.6倍，位于近5年底部。52周最低价55.02元已接近员工持股受让价60.9元，且公司已回购超1亿元。24家机构给出买入/增持评级，目标均价84.24元，较当前价有约45%上行空间。

- **关键催化**：
  - 花知晓并表后的2026年中报/三季报业绩表现
  - 珀莱雅主品牌2026年新品（红宝石微珠精华、源力MED水光喷、械字号等）的销售爬坡
  - 员工持股计划锁定5%增长底线后的超预期可能性
  - 后续可能的品牌出海拓展公告

- **最脆弱假设**：主品牌珀莱雅的营收下滑能在2026年H2企稳甚至转正。若主品牌继续以10%速度下滑，将吞噬所有子品牌的增量。

## 四、看空论证

- **核心观点**：主品牌珀莱雅的渠道调整本质是天猫流量红利见顶后的结构性衰退，而非短期"蓄力"；多品牌增长虽快但体量尚小（合计不足30亿），不足以弥补主品牌76亿基本盘的持续流失；花知晓收购对价偏高且形成大额商誉。

- **主要证据**：

  1. **主品牌下滑幅度远大于市场预期，且未见底信号**：珀莱雅主品牌2025年收入下降10.4%，2026Q1护肤品类继续下降10.6%。天猫直营渠道调整只是推辞——本质是抖音等新渠道分流、竞争加剧、流量成本上升导致ROI恶化。销售费用率2025年同比+1.75pct至49.63%，2026Q1更飙升至50.83%（+5.21pct），投入产出比在恶化。

  2. **花知晓收购的整合风险与商誉隐忧**：花知晓评估增值率高达595.76%，评估值28.27亿对应PE约10倍（按2025年净利），看起来不贵，但花知晓本质上是高度依赖创始人杨子枫的"个人IP+流量打法"品牌，并表后能否保持增长存疑。且交易将形成大额商誉，若花知晓经营不及预期，减值风险将对利润构成一次性冲击。

  3. **护肤品行业已进入存量博弈，竞争格局恶化**：2026Q1护肤品品类全渠道零售额同比-1.68%，大盘不再增长。国际品牌（欧莱雅、雅诗兰黛）加大本土化投入，新锐品牌以品类创新切割细分市场，珀莱雅腹背受敌。公司2026Q1净利率16.64%，同比下降0.55pct，盈利持续被费用侵蚀。

  4. **员工持股计划目标仅为5%增长，暴露管理层谨慎预期**：在2025年营收105.97亿、净利14.98亿的基础上增长5%，意味着2026年目标净利仅约15.7亿。而花知晓并表本身就能贡献约1.5亿+净利——扣除花知晓贡献后，内生增长目标接近零。这暗示管理层对主业前景并不乐观。

- **关键触发**：
  - 主品牌珀莱雅2026Q2/H1营收继续双位数下滑
  - 花知晓并表后增速放缓或出现整合摩擦
  - 销售费用率持续攀升侵蚀利润率
  - 沪股通持仓出现持续减持

- **最脆弱假设**：花知晓的高增长可持续。花知晓2025-2026Q1的高增受益于出海红利和品类景气，但彩妆品牌生命周期短、竞争壁垒低，一旦增速回落，不仅失去利润增量，还会触发商誉减值。

## 六、当前结论

- **当前更占优的方向**：**看多**

- **理由**：
  1. 估值层面：15.6倍PE已充分price-in过去两年的业绩下滑，向下空间有限（员工持股价60.9元和公司回购价构成安全垫）；
  2. 催化层面：花知晓收购是实质性的利润增厚（按Q1年化贡献约6亿净利），且拓展了彩妆和出海两大增量方向，市场此前未充分定价；
  3. 赔率层面：若主品牌企稳+多品牌兑现增长，当前价位赔率显著优于风险；
  4. 行业层面：国货美妆市占率持续提升的趋势未变，珀莱雅作为龙头享有结构性红利。

- **置信度**：**中**

- **核心不确定性**：
  - 主品牌珀莱雅能否在2026H2止跌企稳，目前尚无法确认
  - 花知晓的整合效果和持续性需要至少2-3个季度验证
  - 若消费大环境进一步走弱，费用率高企的问题将加剧

## 七、接下来必须跟踪的验证点

- **花知晓并表后的首份财报（2026年中报）**：关注花知晓Q2收入利润贡献、合并报表后的整体利润增厚幅度、以及商誉确认规模

- **珀莱雅主品牌2026Q2营收趋势**：能否将同比降幅从Q1的-10.6%收窄至个位数，这是判断主品牌是否见底的核心指标

- **销售费用率拐点**：2026Q1销售费用率已升至50.83%，若Q2继续攀升，将严重影响利润弹性；若企稳回落，则证明渠道调整进入收获期

- **珀莱雅重磅新品的市场反馈**：红宝石微珠精华、源力MED水光喷、械字号产品等2026年新品的线上销售排名和口碑数据

- **沪股通持仓变化**：当前持股18.94%，若出现连续减持需警惕；若在股价反弹中持仓稳定或增持，则是积极信号

- **行业竞争格局动态**：关注国际品牌在中国区的策略调整、抖音等新渠道的流量成本变化、以及护肤品品类整体是否企稳回升
