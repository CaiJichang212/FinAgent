# 迈瑞医疗多空论证（2026-05-23）

## 一、核心争论命题

迈瑞医疗上市以来首次营收净利双降，是集采冲击下的短期阵痛，还是高成长时代终结的长期拐点？当前约23倍PE是否已充分定价悲观预期，还是价值陷阱？

## 三、看多论证

- **核心观点**：迈瑞正处于从"国产设备龙头"向"全球医械巨头"转型的阵痛期，国内业务已见底回升，海外+新兴业务将驱动新一轮增长，当前估值处于历史低位，是黄金坑而非价值陷阱。

- **主要证据**：

  1. **国内业务拐点已现，2026年有望重回正增长**：2025Q4营收同比+2.86%实现转正，2026Q1营收同比+1.39%延续正增长；合同负债同比+50.18%至33.42亿，订单能见度大幅提升；2025年12月至2026年2月中标额同比+12%，招标数据持续回暖。管理层明确表示2026年国内业务有望实现正增长，2027年进入稳定快速增长阶段。

  2. **海外业务进入加速收获期，份额提升空间巨大**：国际收入占比首次突破50%至53%，2026Q1国际业务同比+15.70%（美元口径+20%），欧洲市场增长超25%。公司海外平均市占率仍仅低个位数，对标GPS（GE、飞利浦、西门子）有5-10倍提升空间。14个国家布局本地化生产，海外员工超3000人，本地化率90%，全球化2.0阶段已成型。目标未来海外收入占比达70%以上。

  3. **IVD流水线卡位驱动耗材放量，商业模式升级**：MT8000流水线2025年国内新增订单超360套、装机近270套，2026Q1新增订单超140套、装机超80套。流水线装机后驱动高毛利试剂长期复购，从"卖设备"转向"卖耗材"的商业模式升级。公司目标3年内将免疫、生化、凝血国内市占率从10%提升至20%，2026Q1已提升至13%，趋势积极。

  4. **新兴业务高速增长，第二增长曲线确立**：微创外科+微创介入+动物医疗2025年增长38.85%，2026Q1增长18.22%，占国内收入23%。惠泰医疗PFA手术量占国内约1/3，微创介入Q1增长25%。手术机器人即将进入注册阶段，长期增长空间广阔。

  5. **估值处于历史绝对低位，安全边际充足**：当前PE(TTM)约23倍，2026年预期PE约22倍，较全球医械龙头平均30倍PE折价27%，较国内可比公司平均41倍PE折价近50%。股价从2021年高点502元跌至153元，累计跌去近70%，已充分反映悲观预期。乐观情景下合理估值2500-3000亿，上行空间28%-54%。

- **关键催化**：
  - 2026Q2-Q3国内业务同比转正确认
  - IVD集采落地后试剂放量超预期
  - H股上市引入国际投资者，估值体系重塑
  - 手术机器人获批上市

- **最脆弱假设**：国内医疗设备采购复苏力度不及预期，2026年国内业务无法实现正增长，则"筑底回升"叙事失效。

## 四、看空论证

- **核心观点**：集采与DRG改革是不可逆的长期趋势，国内业务见顶而非筑底；海外增速换挡、利润率承压，迈瑞的高成长时代已经终结，当前估值仍非底部。

- **主要证据**：

  1. **集采对利润率的侵蚀是长期且不可逆的**：2025年毛利率60.32%（-2.80pp），净利率25.39%（-6.57pp），ROE从32.58%降至21.58%。集采覆盖品类持续扩围（监护仪降价77.6%、IVD试剂降价20%-50%），2026年是集采全面落地的完整承压年。即使量增，价跌对利润的侵蚀远大于量的弥补。全球最低税实施后海外有效税率从10%提至15%，进一步侵蚀净利润4%-5%。

  2. **国内业务"筑底"时间一再推迟，可信度存疑**：管理层从2025Q1开始承诺"国内业务将从三季度迎来重大拐点"，但2025全年国内收入仍暴跌22.97%，2026Q1国内仍降11.13%。"拐点"叙事已连续推迟两次，若2026年仍无法实现正增长，管理层信誉将严重受损。医院采购预算收紧是结构性问题（DRG/DIP改革使设备从"利润中心"变"成本中心"），不是简单的周期性波动。

  3. **海外增速放缓，高增长可持续性存疑**：2025年海外增速仅7.40%，较2024年的21%大幅放缓。高息滞胀、本地货币贬值导致发展中国家采购放缓，地缘冲突增添不确定性。海外市占率提升需要持续高投入（销售费用率+1.1pp），利润贡献可能不及预期。美国专利诉讼（与Teratech超声专利纠纷）可能面临禁售和巨额赔偿，是重大尾部风险。

  4. **商誉减值风险悬顶**：114.65亿商誉占总资产19.34%，主要来自惠泰医疗收购。若惠泰业绩不达预期或行业环境恶化，可能触发大额商誉减值，直接冲击净资产和利润。2025年已出现首次利润大幅下滑，商誉减值测试压力加大。

  5. **收入结构仍以设备为主，波动性大**：约58%收入来自设备一次性销售，耗材+服务占比仍偏低。相比国际巨头（如罗氏IVD试剂占比超80%），迈瑞的收入结构抗周期能力较弱。新兴业务虽增长快，但占比仅16-17%，体量尚不足以对冲传统业务下滑。

- **关键触发**：
  - 2026H1国内业务仍同比下降，"拐点"第三次落空
  - 集采扩围至更多品类，毛利率跌破55%
  - 惠泰医疗业绩不达预期，触发商誉大额减值
  - 美国专利诉讼败诉，面临禁售和赔偿

- **最脆弱假设**：若海外业务保持15%+增速且国内Q2-Q3确实转正，则"高成长终结"的看空叙事将被证伪。

## 五、对照判断

| 维度 | 看多 | 看空 | 当前占优方 |
| :--- | :--- | :--- | :--- |
| **证据直接性** | 合同负债+50%、Q4收入转正、Q1延续正增长，均为已发生事实 | 集采降价、利润率下滑、国内仍降11%，同样为已发生事实 | **接近** |
| **可验证性** | 国内Q2-Q3是否转正、IVD试剂放量节奏，3-6个月内可验证 | 集采扩围节奏、毛利率是否继续下滑，同样3-6个月内可验证 | **接近** |
| **时间敏感度** | 短期占优：Q2-Q3数据若确认转正，将快速催化估值修复 | 长期占优：集采和DRG的结构性影响是5-10年维度的 | **空（长期）** |
| **赔率影响** | 当前PE约23倍处历史低位，上行空间28%-54%（乐观2500-3000亿） | 下行风险：若利润持续下滑，PE可能被动抬升，市值可能跌至1500亿 | **多（赔率不对称）** |
| **管理层信誉** | 管理层多次承诺"拐点"，但已推迟两次 | 管理层"拐点"叙事可信度下降 | **空** |
| **结构性vs周期性** | 国内下滑是周期性（招标回暖+设备更新），终将恢复 | 国内下滑是结构性（DRG/DIP+集采不可逆），天花板已现 | **空（需验证）** |

## 六、当前结论

- **当前更占优的方向**：**暂不站队，偏向看多但需验证**

- **理由**：
  1. 估值层面，23倍PE已处于历史绝对低位，较全球可比公司折价明显，下行空间有限，赔率不对称偏向看多。
  2. 基本面层面，边际改善信号确实存在（Q4收入转正、合同负债+50%、国际业务+15.7%），但国内业务仍降11.13%，"拐点"叙事已推迟两次，需Q2-Q3数据进一步确认。
  3. 结构性风险（集采、DRG）是长期变量，无法在短期证伪，这是看空方最有力的论据。但迈瑞通过商业模式升级（从设备到耗材+服务）和全球化（海外占比53%且持续提升）正在对冲这一风险。
  4. 综合来看，当前更像是一个"赔率有利但胜率待验证"的位置，不宜重仓押注方向，但可逐步建仓等待验证。

- **置信度**：**中**

---

## 七、接下来必须跟踪的验证点

1. **2026Q2-Q3国内业务是否同比转正**：这是最核心的验证点。若Q2国内仍降，"拐点"叙事第三次落空，看空逻辑将显著强化；若Q2国内转正且Q3加速，看多逻辑将得到确认。

2. **IVD试剂收入增速是否持续加速**：MT8000装机后的试剂上量节奏是商业模式升级能否成功的关键。2026Q1国内免疫、凝血增长约10%，需观察是否加速至15%+。

3. **毛利率是否企稳**：2025年毛利率60.32%已降2.80pp，若继续下滑至58%以下，说明集采对利润率的侵蚀尚未见底；若企稳或回升，则利润弹性将释放。

4. **惠泰医疗业绩与商誉风险**：关注惠泰医疗季度业绩是否达预期，以及年报商誉减值测试结果。若出现大额减值，将直接冲击净资产。

5. **美国专利诉讼进展**：与Teratech的超声专利纠纷若败诉，可能面临美国市场禁售和巨额赔偿，是重大尾部风险。

6. **H股上市进展与估值锚定**：港股上市后国际投资者的定价将提供新的估值参考，可能重塑估值体系。
