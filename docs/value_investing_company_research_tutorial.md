## 1. 价值投资研究的目标

价值投资研究不是“找低市盈率股票”，而是回答四个问题：

1. **这家公司到底赚什么钱？** 也就是商业模式、客户、产品、成本结构、现金流来源。
2. **它能不能长期赚钱？** 也就是行业结构、竞争优势、资本回报率、再投资空间。
3. **它值多少钱？** 也就是用资产价值、收益能力价值、自由现金流折现、相对估值等方法交叉验证。
4. **当前价格是否足够便宜？** 也就是内在价值与市场价格之间是否存在足够的安全边际。

经典价值投资传统强调：股票代表企业所有权，价格与价值并不总是一致；研究者应估算企业内在价值，并在价格显著低于价值时买入。Benjamin Graham 与 David Dodd 在哥伦比亚商学院发展出的价值投资传统，核心概念包括内在价值、安全边际和“市场先生”。[R10]

更现代的价值投资研究，不应只停留在资产负债表和低估值倍数上，还应理解企业的竞争地位、管理层资本配置、可持续增长质量和自由现金流创造能力。[R11]

## 2. 研究流程总览

### 2.1 一页流程图

```text
确定能力圈与问题
        ↓
收集资料：10-K / 年报 / 10-Q / 季报 / 8-K / 代理委托书 / 电话会 / 竞品资料
        ↓
理解商业模式：产品、客户、收入、成本、现金转换、资本需求
        ↓
分析行业结构：需求、供给、竞争、监管、周期、替代品
        ↓
分析财务：三表、利润率、ROIC、现金流、杠杆、营运资本、稀释
        ↓
判断护城河：无形资产、转换成本、网络效应、成本优势、有效规模
        ↓
评估管理层：激励、诚信、资本配置、并购、回购、分红、债务
        ↓
估值：资产价值 / EPV / DCF / Owner Earnings / 相对估值 / SOTP
        ↓
建立情景：熊市、基准、牛市；列出关键变量和敏感性
        ↓
安全边际与仓位：买入价、观察价、卖出条件、跟踪指标
        ↓
形成结论：买入 / 观察 / 放弃
```

### 2.2 研究不是线性流程

真实研究通常是循环式的：

- 商业模式没有看懂，就不要急着估值。
- 财务数据异常，要回到脚注、会计政策和管理层讨论。
- 估值结果非常便宜，要先问“市场为什么会给这个价格”。
- 发现护城河很强，也要问“价格是否已经反映甚至高估了这种优秀”。
- 发现估值很低，也要问“这是不是价值陷阱”。

### 2.3 最终输出

一份合格的公司研究应产出以下内容：

| 输出 | 目的 |
|---|---|
| 投资论点 | 一句话说明为什么值得投资或为什么放弃 |
| 商业模式图 | 说明钱从哪里来、成本花在哪里、现金如何沉淀 |
| 10年财务表 | 观察增长、利润率、现金流、资本回报、杠杆和稀释 |
| 行业与竞品表 | 判断公司是否真的优于同业 |
| 护城河证据 | 用数据证明竞争优势，而不是用形容词描述 |
| 管理层评估 | 判断是否以股东长期价值为中心 |
| 估值模型 | 熊市、基准、牛市三种情景 |
| 风险清单 | 写清楚什么会让投资论点失效 |
| 跟踪清单 | 明确未来每季、每年要看什么 |

## 3. 资料收集：先读一手资料

### 3.1 资料优先级

价值投资研究应优先使用一手资料，再使用二手资料验证和补充。

| 优先级 | 资料 | 用途 |
|---|---|---|
| 一级 | 年报、10-K、招股书、监管文件、审计财报 | 最权威地了解业务、风险、财务和会计政策 |
| 一级 | 季报、10-Q、8-K、重大公告 | 跟踪最新变化、重大事件和短期经营趋势 |
| 一级 | 代理委托书、股东大会文件 | 研究董事会、管理层薪酬、股权激励、治理结构 |
| 一级 | 电话会纪要、投资者日材料 | 理解管理层口径、战略重点和关键经营指标 |
| 二级 | 竞争对手年报和行业协会数据 | 做横向对比，避免只听单家公司叙事 |
| 二级 | 客户访谈、供应商信息、招聘、渠道、价格数据 | 验证需求、竞争和单位经济模型 |
| 三级 | 券商报告、媒体报道、博客、社交平台 | 提供线索，但不能替代独立判断 |

美国上市公司通常会披露 10-K、10-Q、8-K 等文件，其中 10-K 是年度报告，包含业务、财务状况和经审计财务报表。美国 SEC 的 EDGAR 可按公司名、ticker 或 CIK 检索这些文件。[R1][R3]

### 3.2 如何读 10-K / 年报

建议不要从第一页逐字读到最后一页，而是按研究目的阅读：

| 阅读顺序 | 章节 | 重点 |
|---|---|---|
| 1 | Business / Item 1 | 公司卖什么、卖给谁、收入来源、细分业务、地理区域 |
| 2 | Risk Factors / Item 1A | 公司自己承认的主要风险，但要警惕模板化语言 |
| 3 | MD&A / Item 7 | 管理层如何解释增长、利润率、现金流和资本开支 |
| 4 | Financial Statements / Item 8 | 三张报表、脚注、会计政策、分部信息 |
| 5 | Notes | 收入确认、租赁、债务、税务、股权激励、并购、或有负债 |
| 6 | Exhibits | 重要合同、债务协议、并购协议、股权计划 |

SEC 对财报阅读的入门说明强调：财务报表通常包括资产负债表、利润表、现金流量表和股东权益表；脚注和管理层讨论与分析同样重要，因为它们解释会计政策、趋势、风险和管理层视角。[R2]

### 3.3 读资料的基本原则

1. **先读原文，再读观点。** 先看年报、财报、脚注和公告，再看媒体和投资者文章。
2. **同时读竞争对手。** 只读目标公司，会容易被管理层叙事影响。
3. **做时间序列。** 至少看 5 年，最好看 10 年；周期性行业要覆盖一个完整周期。
4. **记录原始数据来源。** 每个关键数字要能回溯到财报页码或官方披露。
5. **比较管理层过去说过什么和后来发生了什么。** 这比单次电话会更能检验可信度。

## 4. 第一遍快速筛选：60分钟判断是否值得深挖

第一遍研究的目标不是形成买入结论，而是判断是否值得投入更多时间。

### 4.1 60分钟流程

| 时间 | 动作 | 输出 |
|---|---|---|
| 0-10 分钟 | 看公司简介、收入构成、市值、企业价值、主要业务 | 是否大致在能力圈内 |
| 10-20 分钟 | 看最近 5-10 年收入、毛利率、营业利润率、净利润、FCF | 是否有稳定经营记录 |
| 20-30 分钟 | 看资产负债表：现金、债务、商誉、营运资本、股本变化 | 是否有明显财务风险 |
| 30-40 分钟 | 看行业和竞品估值、增长、利润率、ROIC | 是否有相对优势或异常低估 |
| 40-50 分钟 | 看最近一份年报风险因素和 MD&A | 主要风险是什么 |
| 50-60 分钟 | 粗略估值与反证 | 值得深挖、观察或放弃 |

### 4.2 快速放弃信号

以下情况不一定意味着公司不能投资，但通常意味着研究难度更高，需要更大的安全边际：

- 商业模式看不懂，收入确认复杂，客户真实需求难验证。
- 连续多年自由现金流为负，但管理层只强调“调整后利润”。
- 净利润增长主要来自并购、一次性收益或会计调整。
- 股本长期明显扩张，股权激励严重稀释。
- 债务高、利息覆盖低、再融资压力大。
- 大额商誉和无形资产占比高，且并购整合效果不明。
- 客户或供应商高度集中。
- 监管、诉讼或政治风险难以量化。
- 管理层频繁改变指标、口径或战略目标。
- 估值便宜但核心业务持续衰退，且没有明确止跌机制。

### 4.3 值得深挖的初筛特征

- 业务简单、现金流清晰。
- 历史 ROIC 明显高于资本成本，且有合理解释。
- 自由现金流与会计利润长期匹配。
- 负债可控，利息覆盖充足。
- 管理层持股或薪酬设计与长期股东回报相关。
- 行业短期遇到困难，但公司长期竞争地位未受破坏。
- 市场关注点集中在短期问题，而长期价值驱动因素仍然存在。
- 价格隐含的预期明显悲观，但事实并没有那么差。

## 5. 商业模式分析

商业模式分析的目标是把公司从“股票代码”还原成“真实生意”。

### 5.1 必答问题

1. 公司卖什么产品或服务？
2. 客户是谁？个人、企业、政府、渠道商，还是平台两端用户？
3. 客户为什么买？价格、质量、品牌、便利性、合规、网络效应，还是别无选择？
4. 收入是一次性的、周期性的、订阅式的、交易抽成式的，还是项目制的？
5. 收入增长来自价格、销量、客户数、使用频率、产品组合，还是并购？
6. 毛利率由什么决定？原材料、人工、履约成本、云成本、渠道费、折扣，还是产能利用率？
7. 经营杠杆在哪里？收入增长时，哪些成本固定，哪些成本可变？
8. 资本开支需求高不高？增长是否需要持续投入厂房、库存、门店、服务器或销售队伍？
9. 营运资本是占用现金还是释放现金？客户先付款还是公司先垫资？
10. 公司有没有监管牌照、专利、长期合同或渠道壁垒？
11. 哪些指标最能领先反映业务变化？订单、留存率、客单价、同店销售、ARPU、产能利用率、贷款违约率，还是库存周转？

### 5.2 商业模式图模板

```text
供应商 / 原材料 / 人才 / 技术
        ↓
公司核心资产：品牌、渠道、软件、数据、工厂、牌照、客户关系
        ↓
产品或服务
        ↓
客户群体与购买场景
        ↓
收入模式：价格 × 数量 × 频率 × 留存 × 产品组合
        ↓
成本结构：固定成本 + 可变成本 + 获客成本 + 维护成本
        ↓
现金流：收款周期 - 付款周期 - 库存周期 - 资本开支
        ↓
可分配现金流 / 再投资 / 分红 / 回购 / 偿债
```

### 5.3 单位经济模型

对于很多公司，尤其是平台、软件、消费、零售和金融企业，只看总收入不够，还要拆成单位经济模型。

| 类型 | 常见拆解 |
|---|---|
| 订阅软件 | 客户数 × ARPU × 留存率 - 获客成本 - 服务成本 |
| 零售 | 门店数 × 单店销售 × 毛利率 - 租金 - 人工 - 库存损耗 |
| 消费品 | 销量 × 单价 × 毛利率 - 渠道费用 - 广告费用 |
| 平台 | GMV × take rate - 补贴 - 履约 - 风控 - 技术成本 |
| 银行 | 生息资产 × 净息差 - 信用成本 - 运营成本 |
| 工业 | 出货量 × 单价 - 原材料 - 人工 - 折旧 - 维护资本开支 |

重点不是把公式写得复杂，而是找出最关键的 2-3 个变量。

### 5.4 识别“好生意”的特征

优秀生意通常有以下特征：

- 客户需求长期存在，不依赖单一流行趋势。
- 产品或服务对客户重要，但在客户成本中占比不高，因此有提价空间。
- 增长不需要同比例增加资本投入。
- 现金回收快，应收账款和库存风险低。
- 规模扩大后单位成本下降，或者客户价值提升。
- 公司能够把利润再投入到高回报机会中。
- 不需要长期依赖外部融资维持经营。

## 6. 行业与竞争格局分析

公司质量离不开行业结构。一般公司在优秀行业中可能表现不错，优秀公司在糟糕行业中也可能长期吃力。

### 6.1 行业研究问题

1. 行业需求是增长、成熟还是衰退？
2. 需求是否周期性强？与 GDP、利率、商品价格、地产、广告、资本开支是否相关？
3. 行业供给是否容易增加？新产能建设周期多长？
4. 进入壁垒是什么？资本、技术、品牌、渠道、监管、数据、网络，还是规模？
5. 客户议价能力强不强？客户是否集中？
6. 供应商议价能力强不强？原材料是否稀缺？
7. 替代品风险是什么？
8. 价格竞争是否激烈？行业是否经常打价格战？
9. 行业利润池集中在价值链哪一段？
10. 监管是否会改变行业利润分配？

### 6.2 行业不要只看 TAM

“市场空间大”不等于“公司能赚钱”。价值投资者更关心：

- 公司能拿到多少份额？
- 拿份额需要付出多少营销、补贴或资本开支？
- 增长是否会吸引大量竞争者进入？
- 行业增长是否会被客户、供应商或平台截留？
- 高增长最后能否变成高自由现金流？

### 6.3 竞品对比表

| 指标 | 目标公司 | 竞品A | 竞品B | 竞品C | 观察 |
|---|---:|---:|---:|---:|---|
| 收入增速 |  |  |  |  | 谁在拿份额 |
| 毛利率 |  |  |  |  | 产品差异化或成本优势 |
| 营业利润率 |  |  |  |  | 规模效应和费用纪律 |
| ROIC |  |  |  |  | 是否真正创造价值 |
| FCF 利润率 |  |  |  |  | 利润是否变成现金 |
| 资产周转率 |  |  |  |  | 资本效率 |
| 负债率 |  |  |  |  | 周期下行承受力 |
| 市占率 |  |  |  |  | 竞争位置 |
| 客户留存/复购 |  |  |  |  | 客户黏性 |
| 估值倍数 |  |  |  |  | 市场预期差异 |

## 7. 财务报表分析

CFA Institute 对财务报表分析的描述是：分析者要在公司商业模式、经济环境、行业环境和财务报表之间建立联系，评估企业盈利能力、现金生成能力、偿债能力和未来表现，而不仅仅是计算比率。[R4]

### 7.1 三张报表的关系

| 报表 | 看什么 | 核心问题 |
|---|---|---|
| 利润表 | 收入、成本、费用、利润率、税率 | 公司是否能赚钱，利润从哪里来 |
| 资产负债表 | 资产、负债、权益、现金、债务、营运资本 | 公司需要多少资本，风险有多大 |
| 现金流量表 | 经营现金流、资本开支、融资、回购、分红 | 利润是否转化为现金 |

SEC 对财报的基础说明中，资产负债表反映某一时点的资产、负债和股东权益，利润表反映一段期间收入和费用，现金流量表反映经营、投资和融资现金流。[R2]

### 7.2 10年财务分析表

建议把公司过去 10 年核心指标整理成一张表。周期性行业至少覆盖一个完整周期。

| 指标 | Y-9 | Y-8 | Y-7 | Y-6 | Y-5 | Y-4 | Y-3 | Y-2 | Y-1 | Y0 | 观察 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|
| 收入 |  |  |  |  |  |  |  |  |  |  | 增长稳定性 |
| 毛利率 |  |  |  |  |  |  |  |  |  |  | 定价权/成本压力 |
| 营业利润率 |  |  |  |  |  |  |  |  |  |  | 经营杠杆 |
| 净利润 |  |  |  |  |  |  |  |  |  |  | 盈利周期 |
| 稀释后 EPS |  |  |  |  |  |  |  |  |  |  | 每股价值 |
| 经营现金流 CFO |  |  |  |  |  |  |  |  |  |  | 收现能力 |
| 资本开支 Capex |  |  |  |  |  |  |  |  |  |  | 维护/增长投入 |
| 自由现金流 FCF |  |  |  |  |  |  |  |  |  |  | 可分配现金 |
| FCF 利润率 |  |  |  |  |  |  |  |  |  |  | 现金质量 |
| ROIC |  |  |  |  |  |  |  |  |  |  | 资本回报 |
| ROE |  |  |  |  |  |  |  |  |  |  | 股东权益回报 |
| 现金 |  |  |  |  |  |  |  |  |  |  | 安全垫 |
| 总债务 |  |  |  |  |  |  |  |  |  |  | 财务杠杆 |
| 净债务/EBITDA |  |  |  |  |  |  |  |  |  |  | 偿债压力 |
| 流通股数 |  |  |  |  |  |  |  |  |  |  | 稀释/回购 |
| 分红+回购 |  |  |  |  |  |  |  |  |  |  | 资本返还 |

### 7.3 常用指标与解释

| 类别 | 指标 | 解释 |
|---|---|---|
| 成长 | 收入 CAGR、EPS CAGR、FCF CAGR | 看增长是否真实且可持续 |
| 利润率 | 毛利率、营业利润率、净利率、FCF 利润率 | 看定价权、成本优势、经营杠杆 |
| 效率 | 资产周转率、库存周转、应收周转、应付周转 | 看资本使用效率和现金转换周期 |
| 回报 | ROIC、ROE、ROA | 看公司是否创造超过资本成本的回报 |
| 杠杆 | 净债务/EBITDA、利息覆盖倍数、债务期限 | 看下行周期生存能力 |
| 每股 | EPS、FCF/股、收入/股、账面价值/股 | 看股东是否真正受益 |
| 估值 | P/E、EV/EBIT、EV/EBITDA、EV/FCF、P/B | 看市场预期和相对价格 |

CFA 的财务分析技术框架强调，分析过程应包括明确目的、收集数据、处理数据、分析解释、沟通结论和后续跟踪；比率分析和共同比报表有用，但比率只能告诉你“发生了什么”，不能自动解释“为什么”。[R7]

### 7.4 ROIC 是核心指标之一

ROIC，即投入资本回报率，是判断企业质量的重要指标。

常用公式：

```text
NOPAT = EBIT × (1 - 现金税率或标准化税率)
投入资本 = 有息债务 + 股东权益 - 非经营性现金
ROIC = NOPAT / 平均投入资本
```

也可以从经营资产角度计算：

```text
投入资本 = 经营性营运资本 + 固定资产净额 + 经营性无形资产 + 其他经营资产 - 经营性负债
```

解读原则：

- ROIC 长期高于 WACC，通常说明公司在创造价值。
- ROIC 高但没有再投资空间，价值主要来自现金返还。
- ROIC 高且能持续再投资，价值可能非常大。
- ROIC 突然上升，要检查是否因为资本开支不足、资产减值、外包、一次性因素或会计处理。
- 周期性行业的 ROIC 要看完整周期平均值，不能只看景气高点。

## 8. 盈利质量与会计风险

价值投资者要区分“会计利润”和“所有者可得到的现金”。

### 8.1 利润质量检查

| 问题 | 为什么重要 |
|---|---|
| 经营现金流是否长期接近或高于净利润？ | 如果利润长期不变现，可能存在收入确认、应收账款或资本化问题 |
| 自由现金流是否稳定？ | FCF 才更接近可分配现金 |
| 应收账款是否比收入增长更快？ | 可能说明收款质量下降或渠道压货 |
| 存货是否比销售增长更快？ | 可能意味着需求放缓、跌价风险或生产过剩 |
| 毛利率是否异常提升？ | 需要检查产品组合、价格、成本资本化或一次性因素 |
| 调整后利润与 GAAP/IFRS 利润差距是否扩大？ | 可能说明管理层排除过多真实成本 |
| 股权激励是否被忽略？ | SBC 是真实的股东稀释成本 |
| 大量并购是否掩盖有机增长？ | 并购可制造增长，但不一定创造价值 |
| 商誉是否过高？ | 未来可能减值，也说明过去收购价格可能偏高 |
| 资本开支是否低于维护需求？ | 短期 FCF 可能被高估 |

### 8.2 常见会计红旗

- “一次性费用”每年都出现。
- 公司频繁更换核心经营指标。
- 管理层强调调整后 EBITDA，但现金流弱。
- 收入增长很快，应收账款和合同资产增长更快。
- 库存积压，但毛利率仍然看似稳定。
- 利润增长主要来自税率下降、回购、资产出售或公允价值收益。
- 资本化费用比例上升，导致利润被抬高。
- 大额关联交易、复杂可转债、特殊目的实体或表外义务。
- 审计师更换、内控重大缺陷、监管调查。
- 分部披露越来越少，透明度下降。

### 8.3 Owner Earnings：所有者收益

Warren Buffett 在伯克希尔 1986 年股东信中推广了“Owner Earnings”概念，用于估算企业真正可归属于所有者的经济收益。简化理解是：

```text
Owner Earnings ≈ 净利润
               + 折旧摊销等非现金费用
               ± 其他非现金项目
               - 维持竞争地位和销量所需的平均年度资本开支
               - 维持业务所需的增量营运资本
```

在快速估算中，可以用：

```text
保守自由现金流 ≈ 经营现金流 - 资本开支
```

但要注意：

- 总资本开支中既有维护性资本开支，也有增长性资本开支。
- 高增长公司用 `CFO - Capex` 可能低估当前盈利能力，但也可能揭示增长非常耗钱。
- 维护性资本开支无法精确披露，通常需要根据折旧、产能、行业经验和管理层披露估算。
- 对金融、保险、银行和资源类公司，普通 FCF 公式可能不适用。

## 9. 护城河与可持续竞争优势

护城河不是“公司很有名”，而是“竞争者即使想进来也很难复制其经济回报”。Morningstar 将经济护城河定义为能让企业抵御竞争、长期获得高利润的持久竞争优势，并常见地归纳为五类：无形资产、转换成本、网络效应、成本优势和有效规模。[R12]

### 9.1 五类护城河

| 护城河 | 含义 | 证据 | 风险 |
|---|---|---|---|
| 无形资产 | 品牌、专利、牌照、监管许可、数据 | 提价能力、市场份额、专利保护、合规门槛 | 品牌老化、专利到期、监管变化 |
| 转换成本 | 客户更换供应商成本高 | 低流失率、高续约率、深度嵌入流程 | 新技术降低迁移成本 |
| 网络效应 | 用户越多，产品对每个用户越有价值 | 双边市场流动性、社交关系链、数据反馈 | 多归属、补贴竞争、平台迁移 |
| 成本优势 | 同等产品下成本更低 | 规模采购、物流密度、低成本资源、学习曲线 | 新产能、新技术、成本外部化结束 |
| 有效规模 | 市场容量有限，容不下太多竞争者 | 区域垄断、自然垄断、小市场高份额 | 市场扩大吸引新进入者 |

### 9.2 护城河要用数据验证

可验证的护城河证据包括：

- 长期 ROIC 高于资本成本。
- 毛利率和营业利润率高于同业，并且稳定。
- 公司能在不明显损失份额的情况下提价。
- 客户留存率高，获客成本可控。
- 规模扩大后单位成本下降。
- 市占率稳定或提升，但没有依赖不可持续补贴。
- 竞争者进入多年后仍无法获得合理利润。
- 公司能把现金流再投入到高回报项目。

### 9.3 护城河常见误判

- **高增长 ≠ 护城河。** 高增长行业往往吸引更多竞争，可能压低长期回报。
- **高毛利 ≠ 护城河。** 如果销售费用、研发费用和客户流失也很高，真实经济回报可能一般。
- **大公司 ≠ 护城河。** 规模只有在带来成本、数据、渠道或网络优势时才有价值。
- **品牌知名度 ≠ 护城河。** 品牌必须能带来定价权、复购或低获客成本。
- **监管保护 ≠ 永久护城河。** 监管既能保护利润，也能重新分配利润。

## 10. 管理层与资本配置

优秀管理层不只是“会讲故事”，而是能长期、理性地分配资本。

### 10.1 管理层研究资料

| 资料 | 看什么 |
|---|---|
| 股东信 | 是否讲清楚长期战略、资本配置和错误复盘 |
| 电话会 | 是否坦诚回答问题，是否过度回避关键风险 |
| 代理委托书 | 薪酬指标、股权激励、董事会结构、关联交易 |
| 内部人持股 | 管理层是否与股东利益一致 |
| 并购历史 | 是否高价收购，是否形成商誉减值 |
| 回购历史 | 是否在低估时回购，还是高价回购抵消股权激励 |
| 分红政策 | 是否与现金流和再投资机会匹配 |
| 债务策略 | 是否在景气高点过度加杠杆 |

SEC 的投资者教育材料指出，美国公司需要披露高管薪酬，通常可在代理委托书、10-K 或注册文件中找到；披露内容包括薪酬表、薪酬讨论与分析，以及薪酬与公司绩效之间的关系。[R13] FINRA 对代理委托书的说明也指出，代理材料通常包含董事候选人、高管薪酬、审计师、股东投票事项等信息。[R14]

### 10.2 资本配置优先级

管理层能做的资本配置主要包括：

1. 投入现有业务。
2. 开发新产品或进入相邻市场。
3. 并购。
4. 偿还债务。
5. 分红。
6. 回购股票。
7. 持有现金。

评价标准不是“有没有增长”或“有没有回购”，而是每一元资本是否创造了超过机会成本的每股内在价值。

### 10.3 管理层红旗

- 薪酬指标只看收入、调整后 EBITDA 或股价短期表现，不看 ROIC、FCF 或每股价值。
- 在高估时大量回购，只是为了抵消股权激励稀释。
- 频繁并购，但有机增长弱、商誉高、整合效果差。
- 反复强调宏大 TAM，却不解释单位经济模型。
- 管理层承诺过多，兑现少。
- 不愿承认错误，频繁重设目标。
- 关联交易复杂，董事会独立性弱。
- 使用过多非 GAAP 指标，且调整项长期存在。

## 11. 估值框架

估值不是算出一个精确数字，而是建立“价格、价值、预期、风险”的关系。CFA Institute 对权益估值流程的描述包括：理解业务、预测公司表现、选择估值模型、将预测转化为估值，并形成投资建议；报告应清楚列出事实、假设、风险和敏感性。[R5]

### 11.1 估值前先问三个问题

1. 公司属于哪种资产？
   - 稳定现金流公司
   - 高增长再投资公司
   - 周期性公司
   - 资产重估型公司
   - 金融机构
   - 资源/商品公司
   - 困境反转公司

2. 价值主要来自哪里？
   - 现有资产盈利能力
   - 未来增长
   - 资产清算或重估
   - 周期恢复
   - 成本削减
   - 资本配置改善

3. 最关键的 2-3 个变量是什么？
   - 收入增速
   - 毛利率
   - 营业利润率
   - ROIC
   - 再投资率
   - 折现率
   - 终值增长率
   - 周期中枢价格
   - 信用损失率

### 11.2 资产价值法

适用场景：

- 银行、保险、房地产、投资控股公司。
- 资产负债表重、现金流波动大的企业。
- 清算、困境、深度价值、net-net。
- 周期性行业底部，需要判断资产重置价值。

常用方法：

```text
调整后资产价值 = 现金 + 可变现投资 + 应收账款折扣值 + 存货折扣值
              + 固定资产重置价值或保守清算值
              + 可识别无形资产价值
              - 所有债务和或有负债
```

注意事项：

- 账面价值不等于经济价值。
- 存货、应收账款、商誉和递延所得税资产要打折。
- 表外负债、租赁、养老金、诉讼、环境义务要纳入。
- 对轻资产公司，账面资产可能严重低估品牌、软件、客户关系和数据。

### 11.3 收益能力价值 EPV

EPV，即 Earnings Power Value，适合估算“不增长情况下”的正常化收益价值。

```text
标准化 EBIT
- 标准化现金税
= NOPAT

EPV = NOPAT / WACC
股权价值 = EPV + 非经营资产 - 债务 - 其他优先索取权
```

使用 EPV 的意义：

- 把“现有业务值多少钱”和“增长值多少钱”分开。
- 避免在 DCF 中把过度乐观增长假设隐藏到终值里。
- 对成熟企业、周期性企业和护城河分析很有用。

判断逻辑：

```text
资产价值 > EPV：公司资产回报不足，可能没有护城河，甚至在毁灭价值。
资产价值 ≈ EPV：竞争性行业，超额利润不明显。
EPV > 资产价值：公司可能有竞争优势。
DCF价值 > EPV：增长有价值，但前提是增长能以高于资本成本的回报实现。
```

### 11.4 DCF：自由现金流折现

DCF 的核心思想是：资产价值等于未来预期现金流按风险调整后的折现率折现到今天的现值。Aswath Damodaran 将估值方法分为内在估值、相对估值和实物期权估值，其中内在估值通常基于现金流、增长和风险；DCF 强迫分析者理解企业和关键假设，但输入也可能噪音很大、容易被操纵。[R8]

常用 FCFF 公式：

```text
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 营运资本增加
```

或：

```text
FCFF = EBIT × (1 - 税率) - (资本开支 - 折旧摊销) - 营运资本增加
```

企业价值：

```text
企业价值 = 明确预测期 FCFF 现值 + 终值现值
股权价值 = 企业价值 - 净债务 - 少数股东权益 - 优先股 + 非经营资产
每股价值 = 股权价值 / 稀释后股数
```

CFA Institute 对自由现金流估值的说明中，FCFF 和 FCFE 模型是 DCF 的重要形式；企业自由现金流折现通常使用 WACC，股权价值可由企业价值减去债务等优先索取权得到。[R6]

### 11.5 DCF 的关键陷阱

- 终值占比过高，模型看似精细，实则由远期假设决定。
- 折现率微调导致估值大幅变化。
- 收入增速、利润率、再投资率之间不一致。
- 假设高增长，却没有假设相应资本投入。
- 假设利润率提升，却没有解释竞争为何不压低利润。
- 用 EBITDA、净利润或经营现金流直接替代可分配自由现金流，可能忽略资本开支、营运资本和债权人索取权。
- 对周期性公司用景气高点利润外推。

### 11.6 相对估值

相对估值不是“同行平均多少倍，所以它也值多少倍”，而是比较市场对不同公司现金流质量、增长、风险和资本回报的定价。

| 倍数 | 适用 | 注意事项 |
|---|---|---|
| P/E | 盈利稳定、资本结构差异小的公司 | 受税率、杠杆、一次性损益影响 |
| EV/EBIT | 比 P/E 更适合比较不同资本结构 | 要调整租赁、非经常性项目 |
| EV/EBITDA | 资本开支差异小、折旧政策差异大的行业 | 不能忽略资本开支，慎用于重资产行业 |
| EV/FCF | 现金流稳定公司 | FCF 可能受周期性资本开支影响 |
| P/B | 银行、保险、资产型公司 | 要结合 ROE 和资产质量 |
| P/S | 尚未盈利但毛利结构清晰的公司 | 很容易高估低利润率业务 |
| PEG | 增长与盈利较稳定公司 | 增长质量和资本需求差异很大 |

相对估值应至少控制以下变量：

- 增长率。
- ROIC 或 ROE。
- 利润率和现金流质量。
- 资本结构。
- 周期位置。
- 会计政策。
- 管理层资本配置。
- 护城河持续时间。

### 11.7 情景估值

不要只做一个“目标价”。建议至少做三种情景：

| 情景 | 假设 | 用途 |
|---|---|---|
| 熊市 | 增长放缓、利润率下行、估值倍数收缩、资本成本上升 | 估计永久损失风险 |
| 基准 | 最可能的经营结果 | 判断合理价值 |
| 牛市 | 公司执行顺利、护城河扩大、再投资回报高 | 判断上行空间 |

示例估值表：

## 12. 安全边际、仓位与交易纪律

安全边际不是固定数字，而是对“不确定性”的补偿。公司越难理解、杠杆越高、周期性越强、估值越依赖远期增长，所需安全边际越大。

### 12.1 安全边际参考

| 公司类型 | 研究难度 | 参考安全边际 |
|---|---:|---:|
| 稳定、低杠杆、宽护城河、现金流清晰 | 较低 | 20%-30% |
| 成熟但增长一般、行业竞争正常 | 中等 | 30%-40% |
| 周期性、金融、资源、强监管行业 | 较高 | 40%-60% |
| 困境反转、高杠杆、技术替代风险高 | 很高 | 50%以上，或直接放弃 |

这些数字不是规则，只是研究纪律的起点。真正的安全边际来自保守假设、充分理解和可承受的下行。

### 12.2 买入前必须写清楚

```text
我为什么认为市场错了？
市场现在隐含了什么预期？
我和市场的分歧在哪个变量上？
如果我错了，最可能错在哪里？
什么事实出现时，我必须承认投资论点失效？
```

### 12.3 仓位原则

仓位大小应取决于：

- 对业务和财务的理解程度。
- 下行风险和资产负债表强度。
- 估值折价幅度。
- 论点可验证性。
- 与组合中其他资产的相关性。
- 流动性和极端情景下的退出能力。
- 管理层可信度。

不要仅根据“上行空间”决定仓位。高上行、低确定性、高永久损失风险的投资不应重仓。

## 13. 风险、反证与卖出条件

### 13.1 风险分类

| 风险 | 例子 | 观察指标 |
|---|---|---|
| 商业风险 | 需求衰退、产品失去竞争力 | 收入、订单、留存率、价格、份额 |
| 竞争风险 | 新进入者、价格战、替代品 | 毛利率、营销费用、客户流失 |
| 财务风险 | 高杠杆、再融资困难 | 净债务/EBITDA、利息覆盖、债务期限 |
| 会计风险 | 收入确认激进、调整项过多 | CFO/净利润、应收、库存、非 GAAP 差异 |
| 管理层风险 | 并购冲动、激励错配 | 薪酬指标、回购价格、资本配置历史 |
| 监管风险 | 价格管制、牌照变化、反垄断 | 政策文件、罚款、合规成本 |
| 周期风险 | 商品价格、利率、地产、广告周期 | 行业领先指标、库存、产能 |
| 技术风险 | 新技术替代、平台迁移 | 研发效率、客户采用、新竞品增速 |
| 汇率/地缘风险 | 跨国收入、供应链中断 | 地区收入、成本暴露、制裁 |

### 13.2 反证清单

每个投资论点都要主动寻找反证：

- 最聪明的空头会怎么反驳我？
- 卖方或市场为什么不认可这个逻辑？
- 竞争对手的财报是否证明行业正在恶化？
- 客户是否真的离不开公司？
- 护城河证据是否只是过去周期的结果？
- 管理层是否用叙事掩盖了资本回报下降？
- 估值便宜是否因为未来利润不可持续？
- 如果利率、商品价格、监管或技术路线改变，价值是否会大幅下降？

### 13.3 卖出条件

卖出不应只因为股价波动，而应基于价值、事实和机会成本。

合理卖出原因：

- 股价接近或超过保守内在价值，安全边际消失。
- 投资论点被事实证伪。
- 管理层资本配置明显恶化。
- 护城河受损，ROIC 中枢下降。
- 资产负债表风险上升，永久损失概率增加。
- 发现更高确定性、更高预期回报的机会。
- 初始研究发现重大错误。

不合理卖出原因：

- 股价短期下跌但基本面未变。
- 市场情绪悲观但没有新事实。
- 因为害怕波动而偏离原始研究。
- 只因为有小幅盈利就卖出优秀公司。

#### A. 能力圈

- [ ] 已阅读至少 3-5 年年报或 10-K。
- [ ] 已阅读最近几个季度报告和重大公告。
- [ ] 已阅读代理委托书或治理文件。
- [ ] 已对比至少 2-3 家竞争对手。
- [ ] 已记录所有关键数据来源。

#### C. 商业模式

- [ ] 收入来源清晰。
- [ ] 成本结构清晰。
- [ ] 资本开支需求清晰。
- [ ] 营运资本模式清晰。
- [ ] 客户需求和购买原因清晰。

#### D. 行业

- [ ] 行业增长和周期性已判断。
- [ ] 主要竞争者和替代品已识别。
- [ ] 客户和供应商议价能力已判断。
- [ ] 监管风险已分析。
- [ ] 行业利润池位置已判断。

- [ ] 已区分维护性资本开支和增长性资本开支。

- [ ] 应收账款和库存没有异常恶化。

- [ ] 薪酬指标与长期价值相关。
- [ ] 管理层资本配置历史良好。
- [ ] 回购、分红、并购和债务策略理性。

- [ ] 高股息是否来自不可持续派息？
- [ ] FCF 是否因为削减必要资本开支而暂时好看？
- [ ] 公司是否处于结构性衰退行业？
- [ ] 管理层是否用债务维持分红或回购？
- [ ] 估值便宜是否因为治理问题无法改善？

- [ ] 应收、库存、合同资产是否异常？
- [ ] 债务和利息覆盖是否恶化？
- [ ] 管理层是否改变关键口径？
- [ ] 竞争对手是否出现价格战或份额变化？
- [ ] 回购是否在合理价格进行？
- [ ] 投资论点是否仍然成立？
- [ ] 当前价格相对内在价值是否仍有安全边际？
