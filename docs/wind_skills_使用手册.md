# Wind Skills 交易系统使用手册

> 本项目已安装 17 个 Wind 交易相关 Skill，覆盖选股、公司分析研究、交易执行、辅助决策四大类。
> 所有 Skill 均依赖 `wind-mcp-skill` 作为数据底座，使用前请确认已配置 Wind API Key。

---

## 一、选股类（4个）

| 技能名字 | 技能功能 | 什么时候使用 |
|---------|---------|-------------|
| **breakout_candidate_finder_skill** | 筛选形态成熟、放量待发的突破候选股，输出优先级、触发条件与失效边界。评估价格结构、量能条件、催化背景、交易拥挤度 | 需要找突破股时；盘前整理候选池；板块轮动中筛领涨预备股；不想盯全市场，只想聚焦结构最完整的标的 |
| **pullback_opportunity_finder_skill** | 寻找回调充分但趋势未破坏的候选股，定位低吸观察区。区分强势整理、趋势破坏、情绪出清三种回调性质 | 强势板块回调后找"二次上车"机会；不想追高想低吸；区分正常回调与趋势转弱；更新日内/日终低吸观察池 |
| **high_quality_compounder_finder_skill** | 筛选高 ROE、高护城河、可长期复利的核心候选股。评估资本回报、盈利质量、护城河稳定性、再投资空间和管理层资本配置 | 长线投资者选核心复利资产；搭建长期跟踪的高质量公司名单；区分短期热门股和真正可长期复利的公司；核心仓建设 |
| **theme_leader_identification_skill** | 识别热门题材中的龙头、中军、跟随股与掉队股，输出题材阶段、驱动链条与风险提示。判断题材处于启动、强化、扩散还是退潮阶段 | 热点题材升温后判断谁最核心；题材轮动中避免把跟风股当龙头；盘后复盘整理题材内部地位变化；新题材爆发时快速建立主线梯队 |

## 二、公司分析研究类（5个）

| 技能名字 | 技能功能 | 什么时候使用 |
|---------|---------|-------------|
| **business_model_decoder_skill** | 把公司如何获客、交付、定价、赚钱和扩张的逻辑拆解清楚，帮助快速理解业务运转方式。拆分收入引擎、成本结构、增长驱动与脆弱点 | 看不懂公司业务、研究前补基础；业务结构梳理；需要把复杂业务压缩成可理解的模块；快速建立对收入来源、成本结构、增长驱动的认知 |
| **moat_strength_review_skill** | 评估公司竞争优势的来源、强度、可持续性与削弱风险，判断护城河是否真实存在并能转化为回报。输出护城河等级、证据矩阵与跟踪信号 | 长线票初筛、优质公司研究；判断竞争壁垒是否真实；区分短期领先与结构性优势；评估"好公司"与"好股票"的差异 |
| **bull_bear_case_builder_skill** | 同时搭建看多与看空逻辑，比较证据强弱、关键变量与情景路径，帮助识别核心分歧。防止确认偏误，输出对照判断与验证跟踪清单 | 防止确认偏误、研究前辩论；投资观点校验；已有初步看法但想检验反面逻辑；识别当前最值得争论的变量 |
| **peer_comparison_decision_skill** | 横向比较同业候选公司的业务质量、增长、盈利、估值与催化差异，并给出相对强弱结论与排序。统一比较框架，输出决策建议 | 候选股二选一或优中选优；行业内建立优先跟踪顺序；比较"谁更值得现在买入"而非"谁绝对更好"；区分综合选择、预期差选择与观察标的 |
| **equity-investment-thesis** | 个股核心投资逻辑深度研究，输出接近券商研究员风格的个股分析报告。覆盖商业模式、行业格局、投资逻辑、预期差、风险与结论 | 输入一个股票名称后需要高质量个股分析；中长线投资研究；需要专业深度的投资视角而非百科式介绍；区分短期催化与中期逻辑 |

## 三、交易执行类（4个）

| 技能名字 | 技能功能 | 什么时候使用 |
|---------|---------|-------------|
| **trade_plan_builder_skill** | 为单笔交易生成完整执行计划，包含入场条件、仓位安排、止损止盈、验证节点与应急动作。回答"为什么做、何时做、做多少、错了怎么办、对了怎么处理" | 看好某股但还没形成可执行方案；盘前把候选股写成标准化计划可比较；团队交易前做结构化复核；想把"想法"与"动作"拆开 |
| **stop_loss_discipline_skill** | 设计价格止损、逻辑止损与时间止损三类规则，并给出触发后的执行动作与复核顺序。区分噪音波动与真正失效 | 下单前先把止损纪律写清楚；持仓进入不利状态不确定是否该处理；经常"知道该止损但下不了手"；统一止损语言减少盘中争论 |
| **take_profit_ladder_skill** | 为盈利仓设计分批止盈路径、保本上移规则与继续持有条件。平衡兑现收益与保留趋势利润，建立可重复执行的卖出框架 | 持仓盈利不知道该一次卖、分批卖还是继续拿；强势股快速上冲担心"卖飞"和"利润回吐"；波段交易接近目标需设计退出节奏；标准化卖出纪律 |
| **position_sizing_decision_skill** | 按风险预算和波动水平给出单笔仓位与分批建仓建议。先量化可承受损失再反推资金规模，同时考虑组合相关性 | 方向看对了但不知道单笔该下多少；多个候选同时存在需决定谁配大仓谁试错；市场波动加大后重新校准风险暴露；避免"一把梭"和随意加码 |

## 四、辅助决策类（4个）

| 技能名字 | 技能功能 | 什么时候使用 |
|---------|---------|-------------|
| **valuation_snapshot_skill** | 快速判断个股估值高低、历史分位、同业相对位置与重估条件。回答"这只股票现在大致贵不贵"，解释估值背后的市场预期 | 先判断"贵不贵"再做决策；估值位置筛查；讨论赔率与预期要求；理解溢价或折价是否合理 |
| **position-sizer** | 计算风险导向的具体持仓股数。支持三种算法：固定比例法（默认1%风险）、ATR波动法、凯利公式法。输出精确股数、仓位价值、止损价 | 问"该买多少股"；需要具体算持仓规模；想用凯利公式或ATR算仓位；检查单笔仓位是否超出组合集中度限制 |
| **backtest-expert** | 量化策略系统化回测与验证。核心哲学是"找出最少出错的策略"而非"纸上盈利最多的策略"。覆盖参数鲁棒性测试、滑点建模、偏差防止 | 开发或验证量化策略；评估交易想法是否足够稳健；排查回测为何可能误导；避免过拟合、前视偏差、幸存者偏差；设置合理的滑点和执行成本预期 |
| **market_regime_switch_skill** | 判断市场处于进攻、防守、震荡或切换阶段，解释风格、广度、情绪与宏观环境的匹配关系。输出市场分档、证据框架、切换线索 | 决定总仓位高低；选择成长、价值、周期或防御风格；周度策略更新；判断市场状态是否正在切换，切换由什么驱动 |

## 交易流程速查

一个完整的交易闭环建议按以下顺序调用技能：

```
1. market_regime_switch_skill     → 判断当前市场环境（进攻/防守/震荡/切换）
2. 选股类 skill（按需选一个）      → 选出候选股
3. 公司分析研究类 skill（按需选一个）→ 深入分析候选股（业务模式/护城河/多空论证/同业比选/投资逻辑）
4. valuation_snapshot_skill       → 判断候选股估值贵不贵
5. position_sizing_decision_skill → 决定单笔仓位大小
6. trade_plan_builder_skill       → 生成完整交易计划
7. stop_loss_discipline_skill     → 设定止损纪律
8. take_profit_ladder_skill       → 持仓盈利后设计分批止盈
9. position-sizer                 → 计算精确买入股数
10. backtest-expert               → 策略上线前做系统化回测验证
```
