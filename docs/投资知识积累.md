# 投资知识积累

## 财务术语

### ROIC — 投资资本回报率

- **全称**：Return on Invested Capital
- **定义**：衡量公司使用全部投入资本（包括股东权益和有息负债）创造利润的效率
- **计算公式**：`ROIC = 税后营业净利润 / 投入资本`
  - 税后营业净利润 = 净利润 + 利息费用（扣除税的影响）
  - 投入资本 = 股东权益 + 有息负债
- **含义**：每投入1块钱资本，能赚回多少净利润
- **参考标准**：
  - ROIC < 10%：盈利能力较弱
  - ROIC 10%-15%：一般水平
  - ROIC > 15%：盈利能力较强，通常说明公司有护城河
  - ROIC > 20%：优秀，通常具备持续竞争优势
- **实战意义**：
  - 衡量公司真实的"内生增长能力"，不受融资结构影响
  - 持续高ROIC说明公司有护城河（品牌、渠道、技术、成本优势等）
  - ROIC > WACC（加权平均资本成本）才创造价值，否则在"赔钱"
  - 比较不同负债水平的公司时更客观
- **与ROE的区别**：
  - ROE = 净利润 / 股东权益，只看自己钱的回报，可以被杠杆"美化"
  - ROIC = 税后营业利润 / 全部投入资本，更真实地反映经营效率

### ROE — 净资产收益率

- **全称**：Return on Equity
- **定义**：衡量股东投资获得的回报率
- **计算公式**：`ROE = 净利润 / 股东权益`
- **注意**：高ROE可能来自高负债（杠杆），需结合ROIC一起分析

### ROA — 总资产收益率

- **全称**：Return on Assets
- **定义**：衡量公司使用全部资产的赚钱效率
- **计算公式**：`ROA = 净利润 / 总资产`
- **用途**：评估资产利用效率，与ROE配合使用

### FY（Fiscal Year）— 财年

- **全称**：Fiscal Year，即财政年度 / 会计年度
- **含义**：企业用于财务报告的年度周期，不一定是自然年
- **常见用法**：
  - FY2025 = 2025 财年
  - Q4 FY2025 = 2025 财年第四季度
- **注意**：A 股公司财年通常与自然年一致（1/1 - 12/31），但部分港股/美股公司财年起止月份不同（如阿里财年截止3月31日），需注意区分

## 交易策略

### 左侧交易（Left Side Trading）

- **核心定义**：在市场趋势未明确反转前，基于对资产内在价值、市场情绪或技术信号的判断，提前逆势布局的交易策略
- **俗称**：抄底 / 逃顶
- **入场信号**：
  - 估值信号：PE/PB 跌至历史低位（如近 5 年 20% 分位以下）
  - 技术信号：MACD 底背离（价格创新低但指标不创新低）、RSI 超卖（RSI < 30）
  - 情绪信号：市场恐慌情绪蔓延、利空消息出尽后股价不再下跌
- **优势**：
  - 成本优势显著，若判断准确可获得超额收益
  - 适合布局长期价值标的，通过"越跌越买"摊薄成本
- **劣势**：
  - 胜率较低（约 30%-40%），可能买在"半山腰"
  - 持仓周期长，资金利用率低，需承受较大心理压力
  - "地板下还有地下室"的极端情况
- **适合人群**：资金量大、持仓周期长、专业投资者、价值投资者（如巴菲特、段永平低位建仓风格）

### 右侧交易（Right Side Trading）

- **核心定义**：放弃主观预判，等待市场趋势明确确认后，顺着趋势方向操作的策略
- **俗称**：顺势而为
- **入场信号**：
  - 突破信号：股价放量突破关键阻力位（如年线、前期高点、箱体上沿），成交量需放大 20% 以上
  - 技术信号：均线金叉（5 日均线上穿 10 日均线）、MACD 零轴上方金叉
  - 确认信号：突破后站稳 3 个交易日（收盘价均在突破位之上）
- **优势**：
  - 胜率较高（约 55%-70%），避免逆势亏损
  - 顺应市场主升浪，能捕捉趋势性行情的大部分涨幅
  - 心理压力小，浮亏时间短
- **劣势**：
  - 买入成本高于左侧，可能面临"追高站岗"风险
  - 对趋势持续性判断要求高，若遇假突破易导致双杀
- **适合人群**：散户、趋势交易者、量化交易者（如利弗莫尔、海龟交易法则）

### 左侧 vs 右侧：核心对比

| 对比维度 | 左侧交易 | 右侧交易 |
|---------|---------|---------|
| 核心逻辑 | 预判拐点，逆向博弈 | 确认趋势，顺势跟随 |
| 决策依据 | 基本面（估值、业绩）+ 技术背离 + 市场情绪 | 技术突破（关键价位/均线）+ 量能验证 |
| 入场时机 | 趋势未明确，底部/顶部形成前 | 趋势已确认，底部/顶部形成后 |
| 风险特征 | 高风险，高潜在收益 | 低风险，收益更稳健 |
| 持仓体验 | 需承受长期浮亏，心理压力大 | 浮亏时间短，心理确定性强 |
| 资金效率 | 资金占用时间长，效率较低 | 资金周转快，效率较高 |

### 策略选择建议

- **做左侧**：震荡底部、个股错杀、估值历史低位、政策拐点出现时
- **做右侧**：趋势上涨、行情明朗、突破信号确认时
- **方向不明时**：坚决不盲目操作
- **组合策略**：底仓（30%-50%）采用左侧布局 + 浮动仓（20%-30%）采用右侧交易，兼顾安全与收益

## 技术指标

### 振幅（Amplitude）

- **定义**：股票当日最高价与最低价之间的差距占昨日收盘价的百分比
- **计算公式**：`振幅 = (当日最高价 - 当日最低价) / 昨日收盘价 × 100%`
- **含义**：反映股票当天价格波动的剧烈程度
- **参考标准**：
  - 振幅 < 3%：波动较小，行情平稳
  - 振幅 3%-7%：正常波动范围
  - 振幅 > 7%：波动剧烈，可能有重要消息或资金操作
- **实战意义**：
  - 振幅越大，说明多空双方分歧越大
  - 高振幅常出现在：重大利好/利空公布、板块轮动、关键价位突破时
  - 结合成交量分析更有效：放量高振幅通常意味着趋势可能反转或加速

### 换手率（Turnover Rate）

- **定义**：某一段时间内股票的成交量占其流通股本的比例
- **计算公式**：`换手率 = 成交量 / 流通股本 × 100%`
- **含义**：反映股票的流动性和市场关注度
- **参考标准**：
  - 换手率 < 1%：交易清淡，关注度低
  - 换手率 1%-3%：正常交易水平
  - 换手率 3%-7%：交易活跃，有资金关注
  - 换手率 > 7%：非常活跃，可能有主力资金操作
  - 换手率 > 15%：极度活跃，需警惕风险
- **实战意义**：
  - 高换手率说明筹码交换充分，可能是新主力进场或老主力出货
  - 低位高换手：可能是底部吸筹信号
  - 高位高换手：可能是顶部派发信号
  - 连续高换手后若股价滞涨，需警惕回调风险

### 振幅与换手率组合分析

| 组合特征 | 市场含义 | 操作建议 |
|---------|---------|---------|
| 高振幅 + 高换手 | 多空博弈激烈，资金分歧大 | 谨慎观望，等待方向明确 |
| 高振幅 + 低换手 | 价格波动大但参与度低 | 可能是无量炒作，风险较高 |
| 低振幅 + 高换手 | 价格稳定但筹码交换充分 | 可能是主力温和吸筹/派发 |
| 低振幅 + 低换手 | 交易清淡，市场关注度低 | 不适合短线操作 |
