## 五、交易系统与操作策略

### 5.1 交易系统定义（适用于本笔及后续猪周期标的）

依据教程第十章，建立如下系统化规则：

| 模块 | 规则 |
|---|---|
| **市场过滤** | 上证指数收盘价站上MA60且非单边大跌日，允许做多；当前满足（震荡偏强） |
| **股票池** | 非 ST、近 20 日均额＞10 亿、上市＞2 年；牧原满足（20日均额20.73亿） |
| **行业过滤** | 农林牧渔/生猪养殖板块相对强度走强；当前满足（政策催化+资金流入） |
| **入场信号** | A：收盘突破20日高点且量比＞1.5；B：上升趋势中回踩MA20企稳重新站上MA10 |
| **初始止损** | 入场价下方 2×ATR 或近期低点下方（取更近者），按收盘价确认 |
| **仓位规则** | 单笔风险≤账户权益1%；买入股数＝可承受亏损÷每股风险 |
| **加仓规则** | 仅在原仓盈利且止损上移后加仓，总仓位上限30% |
| **退出规则** | 跌破MA20、跌破移动止损、或趋势破坏（均线转空头） |
| **移动止损** | 盈利后上移：跌破近20日低点 或 从高点回撤2×ATR |
| **组合风险** | 单股≤30%、同行业≤40%、总仓位上限80% |
| **复盘** | 每月或每20笔交易复盘一次 |

### 5.2 现有持仓的规则化处理方案（核心操作建议）

**前提确认**：7月1日收盘36.98元，MA20=34.51元，ATR14=1.531元，近20日低点31.81元。

#### 方案A：转为趋势持有（推荐，与当前信号一致）

将原持仓**重新定性为"趋势试探仓"**，按规则设定风控：

1. **重新认定入场价**：以当前价36.98为参考基准（原成本39.753仅作账务记录）；
2. **初始止损价**：max(MA20 - 1×ATR, 近20日低点) 附近
   - 计算一：34.51 - 1.531 = 32.98元
   - 计算二：近20日低点 31.81元
   - **建议止损价：32.80元**（约-11.3% from 现价，-17.5% from 成本），跌破则趋势假设失败，离场
3. **持仓数量校验**：
   - 单笔可承受亏损（1%账户）≈ 2465元
   - 现价到止损每股风险 ≈ 36.98 - 32.80 = 4.18元
   - 规则允许持仓 ≈ 2465 ÷ 4.18 ≈ **590股**，**当前600股基本匹配**，无需加减仓
4. **移动止损规则**：
   - 盈利＞5%（站上38.83）后，止损上移至成本价39.753（保本止损）；
   - 盈利＞10%（站上40.68）后，止损上移至MA20或近10日低点；
   - 后续跌破MA20且次日未收回 → 减半仓；跌破MA60 → 清仓

#### 方案B：保守减亏（若无法承受波动或对趋势存疑）

- 在反弹至 **MA60 附近（39.5-40元）** 减仓300股（半仓），锁定部分头寸、降低成本；
- 剩余300股按方案A规则持有，止损32.80元；
- 此方案牺牲潜在收益换取心理稳定，适合执行力偏弱的投资者。

#### 方案C：严格止损派（纯趋势派，不抄底）

- 若认为"中长期均线仍空头"，严格按教程"只参与完整上升趋势"原则；
- 在 **39.5-40元（MA60）** 无法有效突破时清仓离场，等待站稳MA60且均线多头排列后再重新入场；
- 此方案最保守，但会错过底部反转的第一段利润。

**综合建议**：鉴于基本面（猪周期底部+管理层增持）、资金面（主力17亿流入）、技术面（底部放量突破+ADX走强）三者共振，**优先采用方案A**，但必须严格执行32.80元止损。

## 六、关键风险提示

1. **趋势未确认风险**：中长期均线仍空头排列，7月1日突破尚未站稳20日通道上沿（37.94），存在**假突破、二次探底**可能；
2. **猪周期延迟风险**：能繁母猪去化不足、PSY提升，**周期拐点可能推迟至2027年**，期间股价可能反复；
