## 六、完整交易执行计划

虽然**当前不应买入**，但应该制定好完整的交易计划，一旦反转信号确认，就能按计划执行。以下是基于教程体系的完整计划：

以下任一条件满足后再考虑进场（按可靠性排序）：

| 优先级 | 触发条件 | 说明 | 当前距目标 |
|--------|----------|------|-----------|
| 🥇 | **股价放量站稳5日均线之上** | 短期趋势转好的第一信号，当前5MA≈65元，需股价涨至65元以上并站稳3日 | 约+10% |
| 🥈 | **5MA上穿10MA形成金叉** | 短期均线金叉确认短期趋势反转，当前5MA(65)低于10MA(70)，需等5MA拐头上穿 | 需5MA拐头 |
| 🥉 | **股价回调不破前低55.37并突破前反弹高点** | 形成"更高的低点+更高的高点"结构，确认底部反转 | 需观察后续走势 |

> **注意**：不要试图在条件满足前"提前埋伏"。教程强调："等待下跌趋势结束、股价企稳回升后，再顺着新的上升趋势买入。"

### 6.2 买入策略（条件满足后执行）

#### 方案A：回调买入法（推荐，更稳健）

```
买入条件：
  1. 股价已站稳5日均线（5MA开始走平或拐头向上）
  2. 股价出现缩量回调（回调不破5MA或10MA）
  3. 回调时成交量萎缩至5日均量以下

买点选择：
  - 第一买点：回调至5MA附近（约65元区域）
  - 第二买点（如错过第一买点）：回调至10MA附近

买入方式：
  - 首次建仓：计划仓位的 1/2
  - 不加仓，等待趋势进一步确认
```

#### 方案B：突破买入法（适用于趋势快速反转）

```
买入条件：
  1. 股价放量突破前期反弹高点（约62元或更高）
  2. 突破日成交量大于5日均量的1.5倍
  3. MACD DIFF上穿零轴确认

买点选择：
  - 突破当日或次日小幅回调时买入

止损设置：
  - 突破点下方3%，或突破K线最低价下方
  - 若突破失败（3日内跌回突破点以下），果断离场
```

### 6.3 仓位管理策略

采用教程第八章的**"以损定量"原则**：

```
假设总资金：10万元

单笔最大风险：总资金的 2%（2000元）
单只股票上限：总资金的 30%（30000元）

以损定量公式：
  买入股数 = 最大亏损金额 ÷ (买入价 - 止损价)

示例（假设买入价65元，止损价60元）：
  买入股数 = 2000 ÷ (65-60) = 400股
  买入金额 = 400 × 65 = 26000元（在30%上限内）
```

**仓位纪律**：

| 情形 | 仓位 |
|------|------|
| 趋势刚确认反转（均线刚金叉） | 不超过总资金 20% |
| 趋势确立（5MA>10MA>20MA） | 可加至总资金 25%-30% |
| 趋势减弱或信号不明确 | 减仓至 10% 或清仓 |

### 6.4 止损策略

采用教程第七章的技术位止损+ATR动态止损组合：

| 止损类型 | 具体设置 | 适用阶段 |
|----------|----------|----------|
| **初始止损** | 前低55.37元下方，设置为 **54.50元**（约-16%）或固定比例 **-7%**（取较小者） | 买入后立即设置 |
| **均线止损** | 当股价站上5MA后，以5MA作为止损参考；站上10MA后以10MA为止损参考 | 趋势确认后 |
| **移动止损** | 股价每上涨5%，上移止损位3%（保护利润） | 盈利阶段 |

**硬性止损纪律**：
- ⛔ 任何情况下，单笔亏损不超过总资金的 **2%**
- ⛔ 股价跌破前低55.37元，无条件离场（说明底部判断错误）
- ⛔ 仓位亏损达-7%，机械执行止损，不允许"再看看"

### 6.5 止盈策略

采用教程第六章的**移动止损止盈法**（而非固定比例止盈）：

```
第一阶段（股价站上5MA/10MA）：
  → 止盈止损线设为10MA跌破

第二阶段（5MA上穿20MA，趋势初步确认）：
  → 止盈止损线上移至20MA跌破
  → 可考虑卖出1/3仓位锁定部分利润

第三阶段（均线多头排列，主升浪）：
  → 止盈止损线跟随20MA或60MA
  → 采用"最高点回落10%-15%"作为最终止盈信号

分批止盈参考（投资组合管理，非强制）：
  - 盈利达 +10%：卖出 1/4 锁定利润
  - 盈利达 +20%：再卖出 1/4
  - 剩余 1/2 用移动止损继续持有
```

### 6.6 退出条件（减仓/清仓信号）

以下任一信号出现，立即减仓或清仓：

| 信号 | 动作 |
|------|------|
| 股价跌破5MA且5MA拐头向下 | 减仓 1/2 |
| 5MA下穿10MA形成死叉 | 清仓或留 1/4 观察 |
| 股价跌破前低（55.37） | 无条件清仓 |
| 连续3日缩量下跌 | 减仓 1/2 |
| 高位放量滞涨/放量大跌 | 立即清仓 |

### 6.7 执行检查清单（买入前必须逐条确认）

在每天盘前/盘中对照以下清单：

```
□ 均线系统：5MA是否走平或拐头向上？
□ 股价位置：股价是否站在5MA之上？
□ MACD：DIFF是否在回升？柱状线是否为正？
□ RSI：是否在30-70区间（不在极端超卖/超买）？
□ 成交量：是否出现放量上涨、缩量回调的健康量价关系？
□ 大盘环境：市场整体是否稳定（非暴跌环境）？
□ 止损位：买入前是否已确定止损位？
□ 仓位：是否按"以损定量"计算了买入股数？
```

> **6项以上满足 ✅ 才可执行买入。**
