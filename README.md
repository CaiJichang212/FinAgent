# FinAgent

金融投资研究智能体，基于 AI Skills 实现个股研究、选股分析、交易管理与投资复盘。

## 目录结构

```
FinAgent/
├── .github/workflows/          # GitHub Actions 配置
│   └── sync-to-gitee.yml       # 自动同步到 Gitee 的工作流
├── docs/                       # 投资知识文档
│   ├── wind_skills_使用手册.md  # Wind 金融数据工具使用手册
│   ├── 投资知识积累.md          # 投资知识与经验积累
│   └── 趋势交易系统化教程.md    # 趋势交易系统化教程
├── 交易记录/                    # 交易记录与计划
│   └── {日期}/
│       ├── 市场状态判档.md      # 当日市场状态判断
│       ├── {股票}_交易计划.md   # 具体股票的交易计划
│       ├── {股票}_仓位决策.md   # 仓位管理建议
│       └── {股票}_估值快照.md   # 估值快照分析
├── 公司研究/                    # 个股深度研究
│   └── {公司名}/
│       ├── {公司名}投资研究报告.md    # 投资研究报告
│       ├── {公司名}投资分析.pdf       # PDF 版投资分析
│       ├── {公司名}业务模式拆解.md    # 业务模式拆解
│       ├── {公司名}护城河评估.md      # 竞争优势评估
│       ├── {公司名}多空论证.md        # 多空观点论证
│       └── {公司名}估值快照.md        # 估值快照
├── 选股/                        # 选股筛选结果
│   └── {日期}/
│       ├── 选股-回调机会.md      # 回调买入机会筛选
│       ├── 选股-突破候选筛选.md  # 突破形态候选筛选
│       ├── 选股-题材龙头.md      # 题材龙头股筛选
│       └── 选股-高质量复利.md    # 高质量复利公司筛选
└── .gitignore
```

## 使用说明

### 公司研究
- 个股投资逻辑、业务模式、护城河、多空论证、估值快照等分析
- 报告输出至 `公司研究/{公司名}/` 目录

### 选股筛选
- 高质量复利、回调机会、突破候选、题材龙头等多维度选股
- 结果输出至 `选股/{日期}/` 目录

### 交易管理
- 每日交易计划、仓位决策、止损止盈等执行纪律
- 记录输出至 `交易记录/{日期}/` 目录

### 知识积累
- 投资知识体系、趋势交易教程、工具使用手册等
- 文档位于 `docs/` 目录

## 自动同步

项目已配置 GitHub Actions，每次推送到 GitHub 时会自动同步到 Gitee。
手动同步命令：`git push gitee`
